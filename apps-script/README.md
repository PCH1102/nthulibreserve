# 圖書館預約信 → 自動加入 webapp 通知

預約成功後，圖書館會寄「預約通知函」（寄件者 `cir@my.nthu.edu.tw`）。
這個 Google Apps Script 每 5 分鐘檢查一次信箱，把還沒結束的預約送到 Render 推播後端。
後端用你在 webapp「通知總覽」設定的預設值（開始前／開始後幾分鐘）排好推播；
之後可以在 webapp 裡個別編輯或刪除。

## 安裝（只要做一次，約 5 分鐘，用電腦做比較方便）

> 要用**收得到圖書館預約信的那個 Google 帳號**登入。

1. 打開 <https://script.google.com>，按 **新專案**，左上角把名稱改成「圖書館預約通知」。
2. 把編輯器原本的內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容，按 💾 儲存。
3. 左側 ⚙️ **專案設定**：
   - 時區選 **(GMT+08:00) 台北**
   - 最下方 **指令碼屬性** → 新增屬性：名稱 `TOKEN`，值填你在 Render 設定的 **TICK_TOKEN**
4. 回到編輯器，上方函式選單選 **`testParse`** → **執行**。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往 圖書館預約通知（不安全）」→ 允許。
     （這是你自己的程式，Google 對沒送審的程式都會這樣顯示。）
   - 下方「執行記錄」應該印出最近一封預約信解析出的空間和時間。
5. 函式選 **`setup`** → **執行**。看到「設定完成」就好了。

## 運作細節

- 每 5 分鐘把近 30 天、還沒結束的預約整批送給後端；後端已經有的預約不會被覆蓋，
  所以你在 webapp 做的編輯、刪除都會保留，也不會重複通知。
- Render 重啟資料被清掉時，下一輪（最多 5 分鐘）就會自動補回。
- **取消預約不會自動移除通知**：取消時記得在 webapp 的通知總覽把那筆刪掉。
- 想停用：script.google.com → 左側 ⏰ **觸發條件** → 刪除 `checkBookingMail`。
